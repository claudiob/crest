Crest Source code Documentation

A card your app is saved under.

Crest answers GET /houseaccount.vcf with a contact card. A phone offers to save it, and your next text arrives under a name instead of ten digits.

One line in config/routes.rb

crest 'houseaccount.vcf'

One initializer

Crest.configure do |config|
  config.name  = 'HouseAccount'
  config.url   = 'https://houseaccount.com/'
  config.photo = Rails.root.join 'public/cube.png'
  config.phone = -> { Twilio.sender }
end

A route, not an engine

You name the path, because the filename is your app's own name. And because it is a route, the line goes inside a scope or behind constraints if you want it there — which a mount point cannot do.

Public by definition

The controller descends from ActionController::Base and not from your ApplicationController. A phone fetches the card with no session, so an inherited authentication filter would refuse the one request it answers.

Read again every time

Every setting may be a value or something callable, and a callable is asked on each request. A number read out of the environment is then right in production and in staging, with no restart.

How to install

# in your Gemfile
gem 'crest', '~> 0.1.0'

Crest is below 1.0, so the pin stops short of 0.2.0. The API reference for what is published today is at rubydoc.info/gems/crest.
